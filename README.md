# Amazon Sales Analytics Dashboard

## Project Overview

This project analyzes Amazon sales data to identify sales trends, product performance, and revenue patterns using SQL, Excel, and Power BI.

## Objectives

* Analyze sales data and identify patterns.
* Examine product and revenue performance.
* Perform data analysis using SQL and Excel.
* Visualize key metrics through a Power BI dashboard.

## Tools and Technologies

* SQL
* Microsoft Excel
* Microsoft Power BI

## Project Structure

* **Documentation/** – Project report and supporting documents.
* **SQL/** – SQL queries used in the project.
* **Power BI/** – Dashboard files.
* **Excel/** – Excel workbooks.
